# Manual checks

Things only a person on a real device can check: the browser tests can't hear sound, use touch, or install the app.
Each PR that adds something like this adds a line here. Tick it off once tried, with the device and date, and
delete the ticked lines when the list gets long.

Devices: **T** = the tablet, **P** = a phone, **I** = the installed app (from the home screen), not a browser tab.
